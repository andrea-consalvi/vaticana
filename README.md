Vaticana PDF Downloader — Render Blueprint

Upload app.py, requirements.txt, render.yaml and templates/index.html to GitHub. On Render choose New > Blueprint.

Example: https://digi.vatlib.it/view/MSS_Reg.lat.310

The application preserves the e-codices layout and cancellation/progress behaviour. IIIF image availability, full resolution, server limits, and actual end-to-end PDF creation have not been verified. Render free service memory/disk limits can affect very large manuscripts. Respect Biblioteca Apostolica Vaticana image terms.
